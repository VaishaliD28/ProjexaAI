# ProjexaAI
📌 Project Overview

The Smart University Management System is a web-based application designed to simplify and digitize academic and administrative activities within a university environment. The project provides a centralized platform where students can access attendance, study planners, career tracking, and feedback features, while also introducing innovative modules such as mental wellness monitoring, smart notifications, green campus tracking, and peer-to-peer learning.

The system focuses on improving communication between students and faculty, reducing manual work, and enhancing transparency in academic management. The frontend is developed using HTML, CSS, and JavaScript, while a basic Python–SQLite backend is implemented to store user data for demonstration purposes.

This project is created as an academic prototype to showcase how modern web technologies can be used to build an integrated and user-friendly university management solution, with scope for future enhancements such as advanced analytics and full backend integration.
